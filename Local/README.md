# Local workspace

Use this folder for local-only work products that should stay out of git history.

Suggested use:
- `Local/Captures/` for PIX, RenderDoc, and screenshot captures
- `Local/GpuTiming/` for GPU timing notes, exports, and benchmark dumps
- `Local/Profiling/` for profiling traces and analysis output
- `Local/Scratch/` for temporary experiments and throwaway files

Only the placeholder files in these folders are intended to be committed.
